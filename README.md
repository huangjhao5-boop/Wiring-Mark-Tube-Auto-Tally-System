> **專為電氣控制盤、分電盤、自動控制配線工程設計的圖面視覺化配線與線號標籤（マークチューブ）自動集計系統。**
> 
> 徹底解決傳統人工計算線號管數量繁瑣、容易漏算及圖面核對費時的痛點。支援匯入多頁 PDF / 圖檔，於瀏覽器中直接進行智慧吸附配線，並一鍵匯出符合日本電氣工事規範的 Excel 明細表與多頁標註圖面。

---

## 🌟 核心特色 (Key Features)

### 1. ⚡ 智慧導線吸附與折線作圖 (Intelligent Circuit Snapping)
- **黑線智慧吸附**：點擊底圖時自動捕捉並吸附電氣迴路黑線，精準定位無偏折。
- **智慧回路貼合與交叉點鎖定**：直接點選 A 點與 B 點時，演算法即時取樣底圖回路黑線，優先產生 100% 貼合回路的 L 型正交折線，折點精準鎖定交叉接點（●），告別空白處懸空折線。
- **即時動態正交預覽**：移動滑鼠或觸控筆時，即時動態運算並預覽沿回路吸附的折線虛線與折點標記，所見即所得。
- **標籤智慧置中避讓**：標籤自動置於主要水平/垂直線段中央，不遮蔽 90° 折點與端子符號。
- **即時角度提示**：支援 $0^\circ, 15^\circ, 30^\circ, 45^\circ, 75^\circ, 90^\circ$ 角度自動對齊與視覺化提示。

### 2. 🏷️ 線號管與端子台即時集計 (Mark Tube & Terminal Block Auto-Summary)
- **標籤視覺化標記**：線條中央即時渲染印字標籤（如 `101`, `COM`），端子台連接線路以琥珀色外框突顯。
- **高頻印字智慧動態記憶 (Dynamic Mark Memory - 預留 15~20 常用位)**：
  - **開局極簡純淨**：移除冗餘固定預設字詞，初次啟動初始值為完全空白，不佔用空間與視覺干擾。
  - **隨輸隨記・動態權重排序**：隨著施工輸入線號，系統即時累計次數與時間戳記，在左側設定列與配線確認視窗中自動動態推薦前 **15 ~ 20 個最高頻使用線號**。
  - **秒速點選代入**：單鍵點擊任一記憶標籤立即套用，並具備當前選用狀態光暈標示。
  - **支援記憶重置與持久化**：提供「クリア」按鈕可隨時清除記憶庫，並透過 LocalStorage 跨工作階段自動保存。
- **管徑尺寸自動對應 (日本規格)**：
  - `0.5 ~ 1.25 SQ` $\longrightarrow$ **3.2Φ**
  - `2.0 SQ` $\longrightarrow$ **3.6Φ**
  - `3.5 SQ` $\longrightarrow$ **4.2Φ**
  - （每條配線自動計為 **2 個線號管**，勾選端子台連接自動累計 **1 點端子**）

### 3. 💾 專案存檔 / 讀取 ＆ 自動備份 (Project Save/Load & Auto-Recovery)
- **專案檔案匯出/匯入 (`.json`)**：一鍵將配線座標、線號、顏色、SQ 與端子台屬性打包儲存，隨時重新載入或跨電腦交接。
- **LocalStorage 自動暫存**：意外關閉分頁或刷新時，下次開啟系統將主動提示「一鍵恢復上次未存進度」。

### 4. ↩️ 復原 / 重做機制 (Undo / Redo)
- 支援鍵盤 `Ctrl + Z`（復原）與 `Ctrl + Y`（重做），以及頂部導覽列 `[ ↩️ ]` / `[ ↪️ ]` 按鈕，作圖失誤秒速還原。

### 5. 🔢 線號自動連號遞增模式 (+1 Auto Increment - 支援 16進數 PLC / 10進數 / A~Z)
- 內建符合電氣迴路與 PLC 點位定址規格的智慧進位模式切換：
  - **16進 (PLC 點位 / 控制盤預設)**：依照三菱 (MELSEC)、歐姆龍 (OMRON) 等 PLC 十六進位定址規則，`9` 之後接著 `A, B, C, D, E, F`！
    - 範例：`109` $\to$ **`10A`** $\to$ **`10B`** ... `10F` $\to$ `110`
    - 支援 PLC I/O 格式：`Y099` $\to$ `Y09A`、`X01F` $\to$ `X020`、`9` $\to$ `A` $\to$ `B` ... `F` $\to$ `10`
    - 若結尾為非 16 進位英文字母（如 `R`, `S`, `T`, `U`, `V`, `W`）自動智慧相容切換為字母遞增（`R` $\to$ `S` $\to$ `T`）
  - **10進 (DEC 標準十進位)**：一般電氣控制線號純十進位遞增，`109` $\to$ `110` $\to$ `111`、`001` $\to$ `002`。
  - **A~Z 連番 (字母優先)**：`A` $\to$ `B` $\to$ `C` ... `Z` $\to$ `AA`、`101A` $\to$ `101B`、`TB-A` $\to$ `TB-B`。連續作圖效率提升數倍。

### 6. 📌 A點固定・連續新增B點模式 (Fixed Point A & Consecutive B-Point Mode)
- **母線共用端・星狀配線神器**：針對多組相同迴路（如連續電磁閥線圈 `SOL345` ~ `SOL34F` 均接至同一組 `P24` 電源母線或共用端子台），徹底免除每次都要重複重新點選 A 點的繁瑣作業！
- **極速快捷操作**：
  - **鍵盤快捷**：點擊 B 點時**按住 `Alt` 鍵**，或鍵盤直接按下 **`A` 鍵**（或 `Alt+A`）隨時開啟/關閉固定模式。
  - **觸控與面板切換**：頂部浮動狀態列提供 **`[ 📌 A点固定: ON/OFF ]`** 快捷鈕，左側設定列亦提供專屬固定開關。
- **動態黃金圖標高亮**：A 點固定時畫面上顯示 **`A📌`** 琥珀金專屬光暈與鎖定標記，狀態列即時引導「📌 A點固定中：請點擊下一個B點」。
- **連續極速打點**：固定 A 點後，只需單純依序點選 B1、B2、B3、B4...，系統立即自動以既定線號與尺寸批次生成連線，數秒內完成整排十幾條配線！按 `Esc` 或點擊「取消」即可解除固定。

### 7. 🔍 線號即時搜尋與全圖發光高亮 (Search & Highlight Glow)
- 右側明細輸入線號（如 `101` 或 `COM`），畫面上所有符合的配線立即**以青藍色發光光暈高亮顯示**，其餘非目標線條自動半透明淡化，點擊清單更可直覺聚焦。

### 8. ⚡ 配線多選與一鍵批次修改 (Multi-Select & Batch Edit)
徹底解決連續輸入不同線號（如 `101`, `102`, `103`...）後發現顏色或尺寸設定錯誤、不必一條一條重新修改的困擾：
- **右側清單「複数選択」多選操作列**：
  - 點擊「複数選択」切換多選模式，清單直接提供勾選框並支援 Shift 鍵連續選取。
  - **直覺快速選取**：提供「直近 3 本」、「直近 5 本」或「當頁全選」快捷鍵。
  - **秒速即時變更**：上方浮現色塊面板與尺寸按鈕，點擊顏色或 SQ 即刻全數變更，圖面連動發光高亮！支援一鍵批次切換端子台屬性與一鍵批次刪除。
- **「一括変更」進階對話框（三大選取模式）**：
  - **模式一：直近配線（連續登錄）**：專為連續畫了一批線後發現尺寸或顏色錯誤設計，點選「直近 3 本」、「直近 5 本」或指定數量，即時預覽線號標籤並一鍵置換新 SQ 與新顏色。
  - **模式二：條件置換**：將目前所有特定顏色（如「赤」）且特定規格（如「1.25 SQ」）的配線，一鍵篩選置換為新規格與新色。
  - **模式三：同名線號**：指定同名線號（如 `COM`, `101`）進行一鍵批次設定。

### 9. 🌓 底圖顯示增強 (Contrast / Brightness & CAD Dark Mode)
- 提供底圖亮度與對比度微調滑桿，並支援**黑白反相（CAD 深色模式）**，讓彩色的標註配線更加清晰耀眼！

### 10. 📱 iPad / 觸控筆 (Apple Pencil) / PWA 獨立 App 支援
- **觸控筆長按（0.5秒）加/刪折點**：筆尖停留在黑線上即可隨心所欲插入折點，停在折點上自動刪除。
- **Procreate 類雙觸控修飾手勢**：單指按住螢幕任一處 ＋ 筆尖點擊 ＝ 即刻插入折點。
- **PWA 支援**：iPad Safari 點擊「加入主畫面」，即可作為獨立 App 全螢幕滿版開啟，免除網址列干擾。

### 11. 📊 完整多頁面匯出功能 (Universal Multi-Page Export)
- **Excel (`.xlsx`) & CSV 下載**：自動產生標題篩選下拉選單、尺寸分類統計、合計總數。
- **多頁 PDF 圖面匯出**：可選擇「當前頁」、「全頁面一併輸出」或「指定頁碼（如 1, 3, 5-7）」。
- **高解析 PNG (ZIP) 打包**：多頁圖面自動打包為單一 ZIP 壓縮檔快速下載。

## 🚀 快速啟動 (Quick Start)

本系統為 **純前端單一檔案架構 (Zero-Dependencies Single-File Web App)**，無須安裝複雜的後端環境，**資料 100% 在本地瀏覽器運行，圖面絕對保密不外流**。

### 方法 1：直接於瀏覽器開啟
直接雙擊開啟 `index.html` 即可使用。

### 方法 2：透過本地伺服器運行（推薦，PDF 載入效能最佳）
```bash
# 進入專案目錄
cd wiring-app

# 使用 Python 啟動本地 HTTP 伺服器
python -m http.server 8000

# 於瀏覽器開啟
http://localhost:8000
```

### 方法 3：iPad / 平板在區域網路連線
1. 確認電腦與 iPad 連接相同 Wi-Fi。
2. 查詢電腦本機 IP（Windows 可在 CMD 輸入 `ipconfig`，例如 `192.168.1.100`）。
3. 在 iPad Safari 輸入 `http://192.168.1.100:8000` 即可無線作圖！
